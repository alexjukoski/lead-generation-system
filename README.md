🚀 Sistema de Captura de Leads & Automação

Formulário web moderno integrado a uma automação via Make.com, oferecendo notificações por e-mail em tempo real e redirecionamento direto para o WhatsApp.

🛠️ Tecnologias

Front-End: HTML5, CSS3, JavaScript (Vanilla ES6+)

Automação: Make.com (Webhooks + Gmail)

Integração: WhatsApp Click-to-Chat API

✨ Funcionalidades

Higienização de Dados: Formatação automática e limpeza de caracteres não numéricos no telefone.

Comunicação Assíncrona: Envio seguro de dados via Fetch API sem recarregar a página.

Notificações Instantâneas: Disparo de e-mail estruturado em HTML via Make.com e Gmail.

Redirecionamento WhatsApp: Geração dinâmica de link de chat pré-preenchido.

🚀 Como Executar Localmente

Clone o repositório:

git clone https://github.com/alexjukoski/lead-generation-system.git


Configure a sua URL do Webhook no ficheiro script.js:

const WEBHOOK_URL = "https://hook.us2.make.com/rjsfunfkods9f4m096esrry61b4ne0n9";


Abra o ficheiro index.html no seu navegador ou utilize a extensão Live Server.
